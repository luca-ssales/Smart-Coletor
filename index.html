Lixeira Inteligente

Uma ideia simples para tornar o descarte de resíduos mais eficiente.

Desenvolvemos um protótipo de lixeira inteligente capaz de identificar o nível de resíduos em seu interior. Utilizando um sensor ultrassônico, Arduino e LEDs, nosso projeto mostra como a tecnologia pode ajudar a perceber quando uma lixeira está ficando cheia.

Como a distância é estimada?

Na simulação, consideramos uma lixeira com 30 cm de profundidade e o sensor na parte superior. A distância é calculada por: profundidade × (1 − nível). Esse valor de 30 cm serve apenas de exemplo.

Esta é uma simulação para demonstrar o funcionamento do projeto. Os valores exibidos não vêm de uma lixeira conectada ao sistema.

Componentes

O que usamos no protótipo

Para colocar a ideia em prática, utilizamos componentes simples que trabalham juntos para medir o nível dos resíduos e indicar o resultado.

Arduino

É responsável por receber as informações do sensor, processar as medidas e controlar os LEDs.

É uma placa programável: o código do projeto roda nela.

Sensor ultrassônico HC-SR04

Mede a distância entre o sensor e os resíduos dentro da lixeira.

Um dos “olhos” emite o som e o outro recebe o eco.

LEDs indicadores

Mostram visualmente o nível de preenchimento identificado pelo sistema.

São quatro LEDs, um para cada nível.

Estrutura da lixeira

É onde os componentes são instalados e onde ocorre a medição dos resíduos.

O sensor fica na parte superior, voltado para dentro.

Jumpers e conexões

Permitem conectar os componentes eletrônicos ao Arduino.

São os fios que levam energia e sinais entre as peças.
